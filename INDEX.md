# INDEX — por onde começar (leia primeiro, é curto)

| Se você quer... | Abra |
|---|---|
| Retomar o trabalho / saber o estado de hoje | `STATUS.md` |
| Saber por que algo foi decidido assim | `DECISOES.md` |
| Detalhe antigo de uma mudança (28/10 a 01/11) | `HISTORICO.md` (só se precisar) |
| Visão geral e secrets | `README.md` |
| Mexer em horários, voz, idioma | `src/lang.py`, `src/schedule.py` |
| Mexer em roteiro e tamanho dos vídeos | `src/story.py` (`plano`, `ALVO_MIN`, `PPM`) |
| Mexer em fundos | `src/mc.py`, `fundos/aprovados.txt`, workflow `biblioteca.yml` |
| Mexer na fila do Buffer | `src/fila.py`, workflow `fila.yml` |

## Regras para economizar sessões (conta grátis)
1. Leia só INDEX.md e STATUS.md. Abra código só do arquivo que vai mudar.
2. Um assunto por conversa; ao terminar, atualize o STATUS.md (até ~10 linhas) e encerre.
3. Junte vários pedidos numa mensagem só.
4. Nunca guarde chaves, tokens ou senhas aqui.
