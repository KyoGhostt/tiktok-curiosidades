Política de Privacidade

O app "Curioso em Alta" é de uso pessoal e tem um único usuário: o dono do canal. Ele usa a autorização do Google (YouTube) apenas para enviar vídeos ao canal do próprio dono.

  • Não coletamos, vendemos nem compartilhamos dados de outras pessoas.
  • Os dados de acesso ficam guardados de forma privada e são usados somente para enviar vídeos.
  • O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso das informações recebidas das APIs do Google segue a Política de Dados de Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
